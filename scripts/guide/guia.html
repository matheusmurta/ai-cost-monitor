AI Token Observatory

Guia do projeto · extensão VS Code open source (MIT) · v0.1.0 · outubro/2026

1. O que é

Extensão local-first que mostra tokens, custos e requests dos agentes de IA usados no VS Code — Claude Code, Cline, Roo Code e Kilo Code — lendo os arquivos que essas ferramentas já gravam no disco. Sem conta, sem telemetria, sem rede.

  • Para quem: devs que querem saber quanto e onde estão gastando com agentes de IA.
  • Como: descobre as pastas → lê incrementalmente → indexa num SQLite local → exibe num painel React.
  • Entrega: arquivo ai-token-observatory.vsix (~818 KB).

2. Instalação e uso rápido

code --install-extension ai-token-observatory.vsix
  1. Recarregue a janela e clique no ícone AI Token Observatory na Activity Bar.
  2. A primeira sincronização roda sozinha; depois, watchers + polling mantêm o índice atualizado.
  3. Use os filtros globais (período, ferramenta, provedor, modelo, projeto, sessão). Clicar num gráfico também filtra.

6. Regras de dados

Identidade e deduplicação

  • ID: ${sourceTool}:${sourceRecordId}, gravado por upsert — ressincronizar nunca duplica.
  • Claude Code: várias linhas de streaming da mesma mensagem → vale a última. <synthetic> é ignorado.
  • Totais de tarefa/sessão nunca são somados aos registros por request.

Leitura incremental

  • Checkpoint guarda tamanho, mtime e offset. JSONL continua do offset; linha final incompleta fica para a próxima rodada.
  • Arquivo menor que o offset (truncado/rotacionado) → relê do início e substitui os registros.
  • Fontes JSON inteiras (Cline/Roo/Kilo) são relidas e substituídas por arquivo.

Custo — 3 bases, nesta ordem

BaseQuando
ReportadoA ferramenta gravou o custo (Cline/Roo/Kilo). Zero reportado continua 0.
EstimadoModelo na tabela v1-2026-01 ou em preços customizados. Ollama/LM Studio = 0.
DesconhecidoSem dado confiável → null. Nunca é inventado.
Uso do Claude Code por assinatura aparece como equivalente em API, não como cobrança real.

Total de tokens = input + output + cache read + cache write + reasoning. Campo ausente = desconhecido (≠ 0).

Insights e previsão

  • Anomalias por mediana/MAD com z robusto > 3,5.
  • Amostra mínima: 10 requests, 5 sessões, 7 dias.
  • Previsão do mês: regressão linear diária com faixa de ±1,96·SE.

7. Privacidade e segurança

  • Só campos de uso são indexados; prompts e respostas não são armazenados.
  • Preview do texto original é opcional (desligado por padrão), lido direto da fonte e só dentro das pastas conhecidas.
  • Webview com Content Security Policy restrita e nonce; sem scripts externos.
  • Export CSV protege contra injeção de fórmula; caminhos de workspace só saem se solicitado.
  • Nenhuma chamada de rede, nenhuma telemetria.

9. Desenvolvimento

npm install
npm run typecheck        # tsc --noEmit
npm test                 # vitest: 23 testes
npm run build            # dist/extension.js, dist/sql-wasm.wasm, dist/webview/*
npx @vscode/vsce package --no-dependencies --out ai-token-observatory.vsix
  • F5 abre o Extension Development Host.
  • scripts/smoke-real.ts: valida contra os dados reais da máquina (somente leitura, índice em memória).
  • Testes usam fixtures sintéticas (test/fixtures.ts) — nunca commitar prompts reais.

Adicionar uma nova fonte

  1. Implementar Adapter (listFiles, parseFile, incremental) retornando RawRequest com null no que a fonte não registra.
  2. Registrar a detecção em src/discovery/discovery.ts e o mapeamento em src/sync/sync.ts.
  3. Criar testes com fixtures cobrindo dedup, arquivo parcial e truncamento.

10. Limitações conhecidas

  • Modelos fora da tabela (ex.: copilot/*, cline-pass/*) ficam com custo desconhecido até receberem preço customizado.
  • Tabela de preços estática; precisa de atualização manual.
  • Claude Code não registra duração; em Cline/Roo ela é aproximada pela mensagem seguinte.
  • Kilo Code validado apenas com fixtures.
  • Sem testes de integração dentro do VS Code (@vscode/test-electron).
  • Bundle do painel ~1,2 MB (ECharts completo).
  • O vsce local está quebrado; empacotar via npx @vscode/vsce.
